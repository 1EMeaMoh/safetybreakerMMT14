# 11kV Breaker Safety Inspection

ระบบตรวจสอบความปลอดภัย Breaker 11kV และ LV แบบดิจิทัล

## Features

- รองรับ MV (11kV) 8 ขั้นตอน + LV 3 ขั้นตอน
- ถ่ายภาพหน้าตู้
- GPS Tracking
- Email / LINE / Telegram Notification
- QR Code สำหรับสแกนที่ตู้

## ผู้จัดทำ

- กบรม.1
- หบฟม.1-ฟ
- โรงไฟฟ้าแม่เมาะ การไฟฟ้าฝ่ายผลิตแห่งประเทศไทย (กผฟ.)
